# Powerbuilding Log

Phone workout tracker for the 4-week powerbuilding plan. Open it in Safari on iPhone and tap Share › Add to Home Screen to install it as a full-screen app.

Logs are stored on the phone. Use Plan › Backup and restore to copy logs in from the Claude version or to save a backup.

`index.html` is generated from the Claude project's tracker source; edit there and rebuild rather than editing it here.
